# 图片节点与生图节点设计

## 目标

候选画布先完成两个核心节点：

- 图片节点：上传、拖放或粘贴图片，显示图片，并通过右侧连接点把图片作为参考输入。
- 生图节点：通过左侧连接点接收参考图，在节点下方输入提示词和设置线路、模型及生成参数，结果写回本节点。

不新增第三种相关节点类型，不复制上传、连线、任务、计费或资产存储实现。

## 实现边界

- 图片节点继续使用 `CanvasNodeType.Image`、`uploadImage` 和现有连接资源解析。
- 生图节点继续使用 `CanvasNodeType.Config`、持久生成任务和多图结果恢复链路，产品名称和 UI 统一表达为“生图节点”。
- 图片节点不显示生成面板；生图节点的提示词与参数面板居中贴在节点下方。
- 生图节点空态是结果画框，1–4 张结果仍保存在本节点；4 张显示为 2×2。
- 节点创建菜单采用单行图标与名称布局，不显示说明小字；空白画布只通过双击打开菜单，右键不打开。菜单渲染在不参与画布缩放的 UI 浮层，固定为 300px 宽，不随 `viewport.k` 改变尺寸。

## 验收

- 创建入口能分别新增“图片节点”和“生图节点”。
- 画布空白处双击能在指针位置打开节点列表，右键不会打开该列表；菜单没有说明小字和横向滚动条。
- 画布分别处于 58% 与 100% 缩放时，节点列表的实际像素宽度均为 300px。
- 两种节点标题始终可见，未选中时也能辨认职责。
- 图片节点上传后可连接到生图节点，点击图片节点不会出现提示词或模型参数。
- 生图节点面板包含提示词、参考输入摘要、线路、模型、图片参数与生成按钮。
- Fake Provider 生成 4 张图片后，画布仍只有原两个节点，生图节点内部显示四宫格并持久化。
